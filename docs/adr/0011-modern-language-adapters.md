# ADR-0011: 新しい解析エンジンを版付きのプロジェクト単位アダプターへ分離する

- 状態: 採用
- 日付: 2026-10-31（Asia/Tokyo）
- 関連契約: `GRAPH-001`, `NAME-001`, `RELATION-001`, `LOCATION-001`, `COMMAND-001`, `EXECUTION-001`, `INPUT-001`
- 関連判断: [ADR-0004](0004-language-capabilities.md)、[ADR-0006](0006-portable-refresh-core.md)、[ADR-0009](0009-canonical-python-source-positions.md)

## 背景

旧Python解析器はPython 3.8環境とJedi 0.17系に依存し、内部C++解析器はClang 11のC++ APIに依存する。既存のビルド環境を一度に置換すると、解析エンジンの変更、アプリの変更、既存観測の変化を区別しにくい。Rustではファイル単位よりもCargoの構成単位が意味解析の入力になる。

## 決定

旧解析器の固定環境を維持し、`modern` Pixi環境を追加する。各エンジンはPythonの辞書で表される版付きグラフを返し、共通の検査・位置正規化・schema 25への保存を `script/indexers/graph.py` が担当する。エンジンはSQLite IDや公開処理を所有しない。

| 境界 | 責務 |
| --- | --- |
| Python / C++ / Rustアダプター | 実解析、名前同一性、意味関係、入力位置、診断、完全性 |
| 共通グラフ | 必須集合、識別子、辺の参照先、名前衝突、UTF-8境界を検査 |
| 共通保存 | LFへの改行正規化、schema版照合、一つのSQLトランザクション |
| ネイティブSource Group | 全入力の列挙、変更検出、一つの直列起動、グループ全体の再構築 |
| 既存実行終了処理 | 非ゼロ終了の保持、失敗候補の破棄、以前の索引の保持 |

ネイティブ設定型 `Modern Language Source Group` を追加し、既存のCustomコマンド構築・外部実行境界を再利用する。グループは部分消去を許可せず、変更があれば一つのコマンドで全体を再解析する。マニフェスト、コンパイル設定、アダプター設定も内容比較の入力とする。設定ファイルを明示した入力に含めることで、最後のソースを削除した後にも空の結果へ更新できる。

`cli.py configure` が通常の `.srctrlprj` と版付き `.srctrlcfg` を生成する。Python実行ファイルとアダプターのパスを明示し、起動元の作業ディレクトリに依存しない。GUIでは共通のModernグループとして表示・編集できる。既存Python/C++プロジェクトは自動的に新版へ切り替えず、別プロジェクトまたは明示した設定変更で採用する。

## Python 3.14の意味プロファイル

標準の `ast` を使い、Python 3.14の構文を実際に解析する。対象ソースをimport・実行しない。pattern matching、例外グループ、型パラメーター、型エイリアス、テンプレート文字列、asyncを人工対象で確認する。

スコープ付きの二段階解析で定義を登録してから参照を解決する。プロジェクト内import、相対import、namespace package、クラス基底、`self`や明示的構築から静的に分かるメソッドを扱う。関数とメソッドは共通グラフでそれぞれの種類へ写す。旧Python解析器が全てを関数として保存する点は、共通能力比較時の意図した分類差として記録する。

動的な属性、実行時import、monkey patch、一般の型推論を解決済みと宣言しない。確定できない呼び出しは診断と不完全状態で表し、推測した呼出先を追加しない。旧Jediの完全な意味プロファイルと同一とはしない。旧版との比較は明示した共通の定義・呼出・継承の集合と、独立した期待値で行う。

## 位置と失敗

エンジンのグラフは入力の生UTF-8に対応する。保存前に入力内容が変更されていないか再読込し、CRLFをLFへ正規化して行末CRを含む範囲を補正する。BOMと最終改行の有無は保つ。座標は行・列1始まり、UTF-8バイト、終端込みである。旧Pythonのスカラー位置変換を新版アダプターへ二重適用しない。

旧PythonとModernグループを同じプロジェクトで使う場合は、source rootsを分けて所有ソース集合を重複させない。共通ファイルがある設定はワーカー数に関係なく実行前に拒否し、既存索引を保持する。異なるファイルを持つ併用では、旧Pythonのソースだけを変換してから注入する。

不明プロトコル、DB版不一致、壊れた座標、名前衝突、参照先欠落、解析中に観測した内容変更、未知のSQLite構成を拒否する。SQL途中失敗はrollbackする。構文診断はプロセス異常と分け、診断を持つ不完全なグラフを保存できる。保存前の検査成功をファイルシステム全体の原子的スナップショットや、アプリ公開処理のクラッシュ耐性へ広げない。
