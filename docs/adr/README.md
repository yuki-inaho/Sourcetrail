## 変更時の規則

既存の判断を覆す場合は、元の記録を消さず新しい ADR から「置き換える」と参照する。各 ADR に背景、決定、代替案、影響、検証方法、未達成事項を含める。一般論だけの記録にせず、コード・契約 ID・試験・レポートへの接続を残す。

「採用」は記載した範囲の判断が有効であることを意味する。将来の言語アダプターや障害復旧機構が既に実装されたことを意味しない。
